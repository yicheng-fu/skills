# Output Template

按需裁剪，不要机械保留所有标题。默认以段落叙述为主，列表只用于提高可比性。

````markdown
# <主题名称>文献调研

## 1. 调研目标与范围

说明本次调研回答什么问题，覆盖哪些子问题、时间范围、文献类型与边界。

## 2. 研究背景与问题定义

用完整段落说明问题背景、核心挑战、典型设定与评价关注点。

## 3. 文献检索与分类方法

简要说明检索思路、纳入排除标准，以及为何采用当前分类框架。

## 4. 研究脉络总览

先给出整体脉络，再引出下文的分类或时间演化。

## 5. 主要研究路线

### 5.1 <类别 A>

先概括这一类方法的共同目标、关键思想、主要假设和典型优势。

代表性工作：

- **论文 A**：用完整句子说明其核心方法、主要贡献与影响。
- **论文 B**：用完整句子说明其与前作的差异、实验表现或适用条件。

如有必要，可补充核心公式：

```latex
\mathcal{L}(\theta)=...
```

解释公式在该方法中的作用，以及关键符号含义。

最后总结这一类方法的局限与适用场景，并说明其与其他类别的关系。

### 5.2 <类别 B>

沿用与 5.1 相同的比较口径。

## 6. 代表性工作横向比较

围绕统一维度比较不同类别，例如：

- 问题建模方式
- 核心机制
- 训练或推断成本
- 理论保证
- 数据依赖
- 泛化与鲁棒性

必要时可用表格，但不要让表格替代正文分析。

## 7. 研究现状总结

总结当前领域已达成的共识、尚存分歧、主要瓶颈和典型开放问题。避免写成泛泛的“未来工作”套话。

## 8. 结论

用 1 到 3 段收束全文，指出最值得关注的主线和判断依据。

## 参考文献

按正文出现顺序或主题顺序列出论文标题、年份、venue 与链接。
````

## File Naming

若用户未指定文件名，默认使用：

```text
YYYY-MM-DD-topic-survey.md
```

其中 `topic` 使用简短英文 slug，例如 `diffusion-models`, `offline-rl`, `graph-contrastive-learning`。
