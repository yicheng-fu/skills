# Research Skills

This repo currently contains Codex skills for research 🔬🧐 :

- `literature-survey`: for topic-level literature surveys
- `zotero-better-note-summary`: for single-paper Zotero notes


## literature-survey

Use this skill when you need a structured survey for a topic, question, or paper set.

It is designed for:

- broad paper search and coverage
- organizing papers into a clear taxonomy
- comparing major method families
- selecting representative works
- writing a balanced Markdown survey

Typical output:

- scope and research question
- classification framework
- representative papers by category
- current progress, limits, and future directions

Use it when the goal is to understand a field or method line as a whole.

## zotero-better-note-summary

Use this skill when you need a concise note for one paper, especially for Zotero Better Notes.

It is designed for:

- summarizing a single paper in Chinese by default
- using a fixed three-part structure
- writing high-density, easy-to-scan notes
- optionally creating the note directly in Zotero through the local bridge

Typical output:

- `## Motivation`
- `## Content`
- `## Core Technique` or `## Core Conclusion`

Use it when the goal is to quickly capture the value of one paper and store it in Zotero.
